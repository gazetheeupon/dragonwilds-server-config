    Notes

      How this works: this page reads and writes plain DedicatedServer.ini text entirely in your browser tab. Nothing you upload is ever sent anywhere.

      ServerGuid: the server generates this itself on first run to uniquely identify your server. This tool preserves it untouched if your uploaded file already has one, and simply omits it on a fresh config — the server will create one the first time it starts.

      Troubleshooting

      My server won't start

      Owner ID, Server Name, Default World Name, and Admin Password are all mandatory — the server refuses to start if any of them are missing. This page flags any that are empty before you export.

      I made changes but the server ignored them

      DedicatedServer.ini is only read at startup. Editing it while the server is running has no effect, and Jagex's own documentation notes the changes are simply discarded. Stop the server, replace the file, then start it again.

      My server isn't showing up in the server browser

      Double-check the World Name is spelled exactly (it's case-sensitive), confirm your Owner ID is set, and make sure the server's UDP port(s) are forwarded through your router and firewall.
